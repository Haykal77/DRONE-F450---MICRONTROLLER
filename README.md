Kode flight controller ini digunakan pada mikrokontrol ESP32 WROOM DEVKIT sebagai SLAVE dan ESP32 S3 sebagai MASTER.
Komunikasi antara SLAVE dan MASTER menggunakan ESP-NOW, dimana SLAVE berfungsi sebagai kode utama penggerak drone dan MASTER sebagai data logging dan kontrol PID REAL-TIME.
